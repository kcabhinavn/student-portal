# student-portal
Software Systems Development Assignment 1 template portal


## Getting Started

These instructions will help you get a copy of the project up and running on your local machine for development and testing purposes.

1. Clone the repo
```bash
git clone https://github.com/kcabhinav/student-portal.git
```

2. Install dependencies
```bash
sudo apt install make
```

If you are using macos, you can install make using brew
```bash
brew install make
```

3. Use make to build and run the project
```bash
make run
```
